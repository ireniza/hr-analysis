# HR Analysis — [Undisclosed Company]

Exploratory analysis of a 100-employee database using Python and Excel.

---

## 📊 About the project

Analysis of a 100-employee database to uncover insights about salaries, gender distribution, seniority, and performance across departments.

## 🗂️ Dataset

Simulated dataset with 100 employees and 12 variables:
- Demographics: gender, date of birth, city
- Professional: department, position, education level
- Performance: monthly salary, years of service, performance rating

## 🛠️ Tools

- Microsoft Excel — pivot tables, dynamic charts, dashboard
- Python — pandas, matplotlib
- Google Colab

## 📁 Files

| File | Description |
|---|---|
| `employees.csv` | Raw dataset |
| `hr_analysis.xlsx` | Excel analysis and dashboard |
| `hr_analysis.ipynb` | Python notebook |

## 🔍 Analyses

1. Average salary by department
2. Gender distribution by department
3. Average salary by education level
4. Seniority by department
5. Performance by department

## 📌 Key findings

- Technology leads in salaries driven by market demand, not seniority
- The company shows global gender equity (50/50) with area-specific gaps
- Education level correlates positively with salary — postgraduate earns 140% more than technical level
- Operations and Finance retain employees the longest
